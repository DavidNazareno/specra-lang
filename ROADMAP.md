# Roadmap

## Phase 0

- Stabilize the `.scl` syntax
- Keep the parser and validator small and understandable
- Define a normalized intermediate representation

## Phase 1

- Add enums, lists, optional fields, and richer constraints
- Add a plugin contract for framework targets
- Add automated tests for parser and generators

## Phase 2

- Add AI translation from natural language to `.scl`
- Add AST-aware editing and refactoring
- Add language server support

## Phase 3

- Add plugin-based targets
- Add versioned language specs
- Build open governance and RFC workflows
