# Changelog

All notable changes to Specra should be documented in this file.

The project is pre-1.0 and still evolving, but the changelog should still record meaningful milestones.

## 0.1.0

Initial public repository baseline.

- Established the Nx + pnpm monorepo structure
- Added the `.scl` parser and validator
- Added expectations in the language surface
- Added the normalized semantic model and verification plan generation
- Added AI context artifacts and implementation briefs
- Added the base verifier and the first TypeScript-oriented snapshot extractor
- Added tests, fixtures, and user-facing documentation
